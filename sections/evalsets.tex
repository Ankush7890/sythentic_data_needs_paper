All evaluation and dev splits are released with the code. Every split is exactly class-balanced, and every \harm{} and \instr{} sample carries the rationale of the LLM judge(s) that validated its label. Dev splits are drawn from the same sources as the evaluation splits and are disjoint from them at the level of the conversation \emph{and} of the first user turn, so no dev sample shares a prompt with any evaluation sample.

\subsection{High-stakes}
The four \hs{} splits are the evaluation distributions of \citet{mckenzie2025highstakes}, used as released: open-ended chatbot conversations from Anthropic HH-RLHF~\citep{bai2022training}; MTSamples medical transcriptions handed to an assistant in one long user turn; MTS-Dialog doctor--patient dialogues~\citep{benabacha2023mtsdialog}; and ToolACE tool-calling traces~\citep{liu2024toolace} with the function list in a system prompt. Labels are GPT-4o's 1--10 stakes ratings from that work, binarised at $\ge 8$ (high-stakes) and $\le 3$ (low-stakes); samples in the ambiguous middle band or with rating confidence below 7 were dropped upstream, and each split was subsampled to exact class balance. Samples are labelled independently; there is no cross-class pairing. Sizes: 2\,984 / 604 / 86 / 734 evaluation samples and 1\,028 / 278 / 274 / 328 dev samples.

\subsection{Harmful to a human}
\paragraph{Judge.} A conversation is judged \emph{harmful to a human} if the assistant's response leads to harm to human wellbeing---physical harm, severe psychological harm, financial ruin, loss of safety, exploitation, or endangerment---with minor inconvenience and abstract consequences excluded. The judge returns a label, a confidence, and a one-sentence explanation. Every dilemma-derived sample was judged twice by independent judge passes, and a pair of candidate replies to the same prompt is kept only when both passes agree on both samples \emph{and} the two samples carry opposite labels.

\paragraph{AI-Dilemmas and Daily-Dilemmas.} Sources: the AIRiskDilemmas and DailyDilemmas~\citep{chiu2024dailydilemmas} datasets (Hugging Face \texttt{kellycyy/AIRiskDilemmas}, \texttt{kellycyy/daily\_dilemmas}). Each dilemma with its two candidate actions is rewritten once by an LLM into a first-person user turn and an assistant turn that recommends one of the actions, so that both judge passes read identical text. The positive sample is the action judged harmful, the negative sample the action judged not harmful, for the same user turn. Sizes: 136 / 196 evaluation samples, 46 / 66 dev samples.

\paragraph{Refusal.} Dilemma pairs in which \emph{both} actions were judged harmful, plus 500 harmful conversations sampled from the Anthropic red-team transcripts, each duplicated with the assistant turn replaced by a short refusal drawn from a list of 44 refusal templates and relabelled not harmful. The pair therefore holds the user turn fixed and contrasts a harmful reply with a refusal. Size: 400 evaluation samples (200 pairs), 134 dev samples.

\paragraph{Ant-HH.} Non-harmful samples are single-turn \texttt{chosen} conversations from the HH-RLHF helpful and harmless sets; harmful samples are single-turn transcripts from the HH-RLHF red-team attempts~\citep{ganguli2022red} in the most harmful decile by the released harmlessness score. Each side is sampled to 1\,000 conversations before judging, and samples are kept under the same two-pass agreement rule. This is the only \harm{} split whose classes do not share user turns. Size: 134 evaluation samples, 44 dev samples.

\paragraph{Split.} Samples are grouped by their normalised first user turn, and whole groups are assigned to the evaluation set until it holds 20\% of all pairs; the dev set is one third the size of each evaluation split, drawn from the remaining groups with the same key applied across all four splits at once.

\subsection{Instruction following}
Every \instr{} split is a set of consecutive pairs that share the user turn(s) and differ only in the assistant's final turn: one reply that follows the instruction and one that does not. Positives and negatives are therefore balanced by construction. After construction, every pair is validated by two independent LLM judges (GPT-5.1 and Gemini-2.5-Pro) prompted with a single criterion---did the assistant follow the user's instruction: answer the actual question, respect stated constraints, omit nothing, substitute nothing, and refuse only with reason---and a pair is kept only if both judges agree with the construction label on \emph{both} samples; a disagreement or a failed call on either sample drops the pair. Judge yields ranged from 13\% (unjustified refusal) to 68\% (BBQ substitution). Each split was later extended by about one third with samples built from source items that no existing kept or rejected sample had used; those extension samples form the dev split.

\paragraph{Unjustified refusal (Harmless-refusal).} Single-turn helpful conversations from HH-RLHF (\texttt{helpful-base}, \texttt{chosen}). The positive sample keeps the original helpful reply; the negative sample replaces it with a refusal drawn from the same 44-template list as above. No LLM rewriting. 200 evaluation samples, 68 dev samples.

\paragraph{Biased substitution (BBQ-substitution).} From the BBQ bias benchmark~\citep{parrish2022bbq}. The user turn presents the BBQ context, states a personal preference for the stereotyped (wrong) answer in one of ten phrasings, and asks for an objective answer in one of ten phrasings. The positive reply gives BBQ's correct answer; the negative reply sycophantically returns the answer the user said they preferred. An LLM naturalises the shared user turn once per pair and expands each one-word answer into a full reply that keeps its position. 200 / 68 samples.

\paragraph{Embellishment (MM-substitution).} From the MoralTextManipulation dataset (Hugging Face \texttt{MLNTeam-Unical/MoralTextManipulation}, intensified rewrites), which pairs a human-written text with an LLM rewrite that intensifies its moral framing. Texts are ranked by the cosine distance between the moral-foundation vectors of original and rewrite, filtered to English, and passed through an LLM gate that checks the text is concrete enough to ask a question about. An LLM writes one question per text, which becomes the user turn; the positive reply answers it from the original text (shortened to a direct answer), the negative reply answers it from the intensified rewrite, minimally edited to read as an answer without changing its content. 200 / 68 samples.

\paragraph{Contradicting the source (HC-contradiction).} From a curated set of health yes/no questions (\eg{} whether a named compound is an effective cancer treatment), each with one supporting and one refuting document, shortened and polished by an LLM and filtered for refusals. Each question yields four pairs: supporting or refuting document, crossed with an instruction to answer from the document (twenty phrasings) or to assume the document is wrong (twenty phrasings). The positive reply gives the answer the instruction demands; the negative reply gives the opposite. An LLM turns the bare yes/no into a fluent sentence with the same stance; refusal-shaped rewrites are removed. 200 / 68 samples.

\paragraph{Context drift, retrieved-document flavour (HC-context-drift).} Same health source. Turn one supplies a question and a document and is answered correctly; turn two says ``I found a better source'' in one of thirty phrasings and supplies a second document. The positive reply answers from the second document; the negative reply keeps the first turn's answer. Documents are drawn as disjoint two-supporting / two-refuting chunks per question so that same- and opposite-polarity document pairs are balanced, and at most one chunk per question is used. Bare answers are naturalised by an LLM; pairs whose naturalised turn begins with a refusal are removed. 194 / 66 samples.

\paragraph{Context drift, dialogue flavour (OIG-context-drift).} From the \texttt{infil\_dbpedia} subset of the Open Instruction Generalist corpus~\citep{laion2023oig}. Conversations are filtered to a pool by a length cap over the first four turn pairs and two LLM gates (later turns must not be redundant given earlier ones; every answer must be a coherent part of the conversation). The first two user/assistant pairs form a four-message conversation; the positive sample keeps the original second reply, the negative sample copies the \emph{first} reply into the second slot, paraphrased by an LLM so that the drift is not detectable by string matching. 194 / 66 samples.
