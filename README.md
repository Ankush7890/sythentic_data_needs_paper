## Build
```
python3 make_tables.py               # tables/figures from data/; also writes data/curves.json (every per-split learning curve)
python3 fit_curves.py                # ~7 min: log-logistic fit + 200-replicate bootstrap of every curve -> data/fits.csv,
                                     #         tables/fit_decomp.tex, tables/fit_splits.tex, figures/fit_scatter.tex
python3 fit_curves.py --from-csv     # seconds: redraw those tables/figure from data/fits.csv without refitting
python3 make_predictor_tables.py     # seconds: Appendix D tables from data/knee_predictor*.csv (results of the knee_predictor branch)
latexmk -pdf -f -interaction=nonstopmode main.tex
```
A killed pdflatex can leave NUL bytes in `main.aux`; `rm main.aux` and rebuild.
